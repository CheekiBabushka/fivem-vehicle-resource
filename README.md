# FiveM Vehicle Resource
This is a resource template for a vehicle resource for FiveM for both a ELS vehicle and NON ELS vehicle.

## How to utilise
1. Delete the .gitkeep files inside the **stream** folders, and place your model files into the folders
2. Edit the meta files in the data section to match the model files in trhe stream folder

*If it is a Non ELS vehicle, they will have provided a carcols.meta file for it, use that one*
